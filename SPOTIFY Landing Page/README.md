# 🎵 Spotify Landing Page Clone

A pixel-faithful clone of the Spotify Web Player UI — built as a frontend practice project.

![Spotify Landing Page](https://raw.githubusercontent.com/Deeksha-Mane/Basic_Projects/main/SPOTIFY%20Landing%20Page/Preview.jpeg)

---

## 📌 About

This is a **static frontend clone** of the Spotify Web Player interface. It replicates the look and feel of Spotify's home screen including the sidebar, trending section, featured charts, and the bottom playback bar.

> ⚠️ This project is **not live** and is intended purely for learning and UI practice purposes.

---

## ✨ Features

- 🖤 Dark-themed Spotify-style layout
- 📚 Sidebar with Home, Search, and Your Library sections
- 🔥 "Trending Now Near You" section with album cards
- 📊 "Featured Charts" section (Top 50 Global, Top Songs Global, Top Songs India)
- ▶️ Bottom playback bar with track info, controls, and volume
