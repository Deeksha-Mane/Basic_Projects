# 🐶 TinDog — Tinder for Dogs

A fun and fully responsive landing page for a fictional dog-matching service — built while learning **Bootstrap 5**.

---

## 📌 About

**TinDog** is a mock landing page inspired by Tinder — but for dogs! 🐾  
The goal of this project was to practice and learn **Bootstrap 5** by building a modern, mobile-friendly, multi-section landing page from scratch.

> ⚠️ This is a **practice project** — TinDog is not a real app or service.
